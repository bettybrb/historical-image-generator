# Historical Image Generator

An AI-powered image generation project for creating historically and geographically informed images from natural-language prompts.

The pipeline uses Mistral-7B-Instruct to expand user prompts with additional contextual detail before generating images with DreamShaper-8. The project also includes a Gradio interface and compares baseline image generation with LLM-enhanced prompts.

## Technologies

- Python
- Mistral-7B-Instruct
- DreamShaper-8
- Hugging Face Transformers
- Diffusers
- Gradio
- PyTorch
